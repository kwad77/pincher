`context_for_task` no longer seeds on graph-hub symbols when on-topic candidates exist ([#1846](https://github.com/kwad77/pincher/issues/1846)). A symbol with a very high inbound-CALLS fan-out (e.g. a constructor with 500+ callers) used to win a BM25 seed slot and flood the `callers` array with 50 task-irrelevant rows. Seed selection now defers candidates above a caller-count threshold behind non-hub matches of the same test class — hubs still seed as a last resort, so a corpus where every match is a hub never falls through to the empty-seed path.
