**Java & C# tree-sitter extraction now record constructor-invocation edges ([#1958](https://github.com/kwad77/pincher/issues/1958)).** Closing the same gap fixed for TypeScript: the AST-tier Java and C# extractors only emitted CALLS from method invocations, so `new Foo()` instantiations were dropped vs the regex tier (which counted them via its `name(` scan) — losing the "who instantiates this class" signal `trace`/hotspots rely on. `object_creation_expression` now emits a CALLS edge to the constructed type in both extractors, keeping edge coverage at least as rich as the regex tier. Generic and qualified constructions (`new Foo<T>()`, `new a.b.Foo()`) resolve to the bare type name.
