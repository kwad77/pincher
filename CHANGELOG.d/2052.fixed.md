**`mode=skeleton` interaction bugs fixed ([#2052](https://github.com/kwad77/pincher/issues/2052)).** Three v1.10.0 skeleton-path defects: (1) `symbols(mode=skeleton)` batches rendered each entry against the full `max_tokens` instead of the running budget, so an N-container batch shipped ~N× the budget — entries now budget against `budgetRemaining` and over-budget entries take the same `source_omitted` path as the non-skeleton branch; (2) the `context(mode=skeleton, lite=true)` path re-ran `truncateSourceToTokens` on an already-self-budgeted skeleton, dropping the closing `}` / `… +N more` note — the lite truncation now carries the `!modeSkeleton` guard `handleSymbol` already had; (3) `symbols(mode=skeleton)` with the default compact fieldset (no `source`) stamped `_meta.mode`/`rendered_from`/`disk_verified` advertising an index render that never ran — the batch marker block is now gated on `includeSource`, matching the per-symbol path.
