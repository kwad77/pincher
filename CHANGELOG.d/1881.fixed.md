**`TestUpdateCLI_CheckBinary` no longer skips silently in CI — self-hosted origin temp repo replaces the fetch-availability probe.** The original #1875 hermetic fix (PR #1876) added `t.Skipf` when `git fetch --dry-run origin` failed, which removed the credential-helper flake but caused the test to skip whenever the actions/checkout@v4 extraheader didn't fire on the subprocess. Skipped tests don't exercise the dispatch path through `update.go` → `cmd/pinch` coverage dropped 0.2pp, pushing the 85.0% gate to 84.9% and breaking the Coverage check on downstream PRs (#1873, #1878). This change replaces the skip with a self-hosted origin temp repo (same trick `TestUpdateInRepo_Check` already uses) — the dispatcher always runs, fetch always succeeds locally, no credentials needed, no coverage regression. Same docstring contract; broader code path exercised; CI determinism preserved.
