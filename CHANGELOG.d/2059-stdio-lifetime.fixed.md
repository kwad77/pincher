**HTTP mode now survives stdin EOF without a `tail -f /dev/null` wrapper ([#2059](https://github.com/kwad77/pincher/issues/2059)).** `pincher --http <addr>` keeps the HTTP listener alive after a clean stdio EOF, so shell/background launches whose stdin is `/dev/null` no longer start and immediately tear down the REST server. Stdio-only MCP sessions keep their historical clean-exit behavior, and `--http --no-stdio` remains the explicit detached HTTP-only mode.
