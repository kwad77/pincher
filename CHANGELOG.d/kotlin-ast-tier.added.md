**Kotlin extraction promoted to AST tier (1.0) via real tree-sitter (ADR-0008, Phase 2).** Kotlin `.kt`/`.kts` files now extract through real upstream tree-sitter compiled to WASM (`wazero`, pure-Go / `CGO_ENABLED=0`), behind the per-file all-or-nothing dispatcher; `PINCHER_DISABLE_KOTLIN_AST=1` reverts to the regex tier. `class`/`data class` → Class, `interface`/`fun interface`/`sealed interface` → Interface, `enum class` → Enum, `object`/named `companion object` → Class (anonymous companion objects keep their members scoped to the enclosing class, matching the regex tier); `fun` → Method inside a type or Function at top level. QNs are `moduleQN`-keyed with `.` (namespace-blind). `import` declarations emit IMPORTS (net-new). Measured on okhttp (525 files): **6.3% parse errors** (2 in 33 files gracefully fall back — Kotlin's community grammar is slightly less mature, like Swift; never worse than before), types near-exact (Class/Enum/Interface), **+5620 net-new IMPORTS**, and a richer CALLS graph (27754→47405). The lower raw agreement (86.3%) is tree-sitter correctly reclassifying methods the scope-blind regex tier mis-emitted as top-level functions. Validated by inline unit + no-leak (3000 reuses) + fuzz; full `internal/ast` suite + `make corpus-test` green (no `.kt` in fixtures). Cost: binary +~4 MB (Kotlin's grammar is the largest yet; wasm 16.3→20.3 MB). **Breaking note:** re-indexing a Kotlin project changes some symbol IDs where tree-sitter scopes more precisely than the old regex tier.
