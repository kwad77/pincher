**Rust extraction promoted to AST tier (1.0) via real tree-sitter ([#1957](https://github.com/kwad77/pincher/issues/1957), ADR-0008).** Rust `.rs` files now extract through real upstream tree-sitter compiled to WASM (run by `wazero`, pure-Go / `CGO_ENABLED=0`) instead of the regex tier. The dispatcher is per-file all-or-nothing: a clean parse (`HasError()==false`) yields AST-exact symbols at confidence **1.0** with full grouped-`use` import enumeration and `impl Trait for Type` method qualification (the #1783 fix, native); any parse error or `PINCHER_DISABLE_RUST_AST=1` falls back to the regex tier (0.85) — graceful degradation, never worse than before. Symbol QNs/IDs match the regex convention exactly (`moduleQN`, trait-qualified method QNs, per-file CALLS at 0.6 confidence) to minimize symbol-ID churn on the upgrade re-index; cached IDs that *do* change resolve via re-query (`search`). Thread-safe across the concurrent indexer via a bounded (≤4) instance pool. The in-tree `wazero↔tree-sitter` binding (`internal/tsbridge`) gained a full WASM free lifecycle (`ts_tree_delete` + per-node frees), validated by a no-leak-under-3000-reuses test (RSS stays flat) and a marshaler fuzz target (180k+ execs, no panic). Binary size +~4 MB (37→41 MB); first Rust file pays a one-time ~0.2s pool warmup. **Breaking note:** re-indexing a Rust project changes some symbol IDs where tree-sitter scopes more precisely than the old regex tier — announced, not silent.
