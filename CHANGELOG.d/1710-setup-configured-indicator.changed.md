The `pincher setup` wizard now shows which hosts pincher is already wired into ([#1710](https://github.com/kwad77/pincher/issues/1710) v0.92). The host checklist tagged editors `·detected` (the editor is installed) but gave no signal whether pincher's policy block was already in that editor's config — so a re-run couldn't tell "done" from "to-do". A host whose config already carries a pincher block now renders a green `·configured` tag, which supersedes the dimmer `·detected`.
