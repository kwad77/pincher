`audit_unused` no longer emits confidently-wrong dead-code verdicts while the indexer is mid-pass ([#1847](https://github.com/kwad77/pincher/issues/1847)). During the resolve pass, inbound CALLS edges are not yet populated, so every function — including live entry points reachable only from `func main()` — looked unreachable; `audit_unused` would report them at `confidence: high` with `deep_trace_confirms_unreachable` evidence. It now refuses with a `retry once indexing finishes` error when the call graph is incomplete, rather than ship a verdict that would delete the CLI.
