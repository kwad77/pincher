**TypeScript & TSX extraction promoted to AST tier (1.0) via real tree-sitter ([#1958](https://github.com/kwad77/pincher/issues/1958), ADR-0008).** `.ts` and `.tsx` files now extract through real upstream tree-sitter compiled to WASM (`wazero`, pure-Go / `CGO_ENABLED=0`) — completing the Phase-1 set (Rust, Java, C#, TypeScript). Two grammars (`tree_sitter_typescript` for `.ts`, `tree_sitter_tsx` for `.tsx`) behind the per-file all-or-nothing dispatcher; `PINCHER_DISABLE_TS_AST=1` reverts to the regex tier. No collision with the existing JavaScript AST path — TS had no prior AST tier, and the JS `tdewolff` extractor is JS-only. The extractor reproduces the TS regex tier's full convention surface so symbol IDs stay stable: funcStack-scoped local-variable QNs (`module.fn.innerFn.var`), namespace scoping (a class inside a namespace stays moduleQN-based, matching the regex single-slot model), Variable `Parent` stamping, object-literal methods, arrow-function-as-const, and **receiver-type-aware CALLS** (`this.X()` → enclosing class; typed `c: Cart` → `Cart`; bottom types like `any`/`unknown` → empty). Measured on zod (401 files): **1.0% parse errors** (the remaining files gracefully fall back to regex — never worse than before), **96.2% symbol agreement with exact parity on every type kind**, and a **16× richer CALLS graph** (tree-sitter walks every call expression vs the regex tier's same-line-only pass) — a large win for `trace`/`neighborhood`. Validated by inline unit tests (incl. a TSX/JSX parse), a no-leak-under-3000-reuses RSS test, a marshaler fuzz target, and a gated differential. **Cost:** binary +~3 MB (two grammars; wasm 7.5→10.4 MB, binary ~47→50 MB). **Breaking note:** re-indexing a TS project changes some symbol IDs where tree-sitter scopes more precisely than the old regex tier — announced, not silent.
