**Tree-sitter AST infrastructure — vendored wazero binding + experimental Rust extractor ([#1957](https://github.com/kwad77/pincher/issues/1957), ADR-0008).** Lands the foundation for AST-tier (1.0) extraction via real upstream tree-sitter compiled to WASM: `internal/tsbridge/` (the wazero↔tree-sitter binding, vendored+adapted from `malivvan/tree-sitter` MIT, plus a `zig cc`-built `ts.wasm` embedding the real tree-sitter Rust grammar) and an experimental Rust extractor mapping tree-sitter nodes onto pincher's `ExtractedSymbol`/`Edge`. **No production behavior change** — the extractor is not wired into the registry/dispatcher; it's exercised by a gated differential test (`PINCHER_SPIKE_CORPUS`). Pure-Go / `CGO_ENABLED=0` preserved; binary size unchanged while gated (dead-code-eliminated until wired). Differential vs the regex tier on the ripgrep corpus: **97.5% (name,kind) symbol agreement** (Class/Enum/Interface counts identical), with IMPORTS 3.2× (grouped use-trees enumerated) and a richer CALLS graph (1.33×). New runtime dep: `github.com/tetratelabs/wazero` (Apache-2.0); attributions added to NOTICE.
