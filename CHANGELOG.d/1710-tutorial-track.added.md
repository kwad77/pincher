A four-stop tutorial track on the GitHub Pages site ([#1710](https://github.com/kwad77/pincher/issues/1710) v0.92). `docs/tutorial.html` is a hub linking four styled, hands-on pages — Getting started, Working with the graph, Composites & the `_meta` envelope, and Dashboard & operations — that take a new user from a fresh install to fluent. The 7 existing per-host walkthroughs were previously unreachable from the landing page; the hub now surfaces them and `docs/index.html` gains a `Tutorial` nav entry. Shared styling lives in `docs/assets/tutorial.css`, matching the landing page.
