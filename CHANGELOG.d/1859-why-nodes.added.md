Go design-rationale comments are now extracted as queryable `Rationale` symbols ([#1859](https://github.com/kwad77/pincher/issues/1859)). A `// NOTE:` / `// HACK:` / `// WHY:` / `// FIXME:` / `// XXX:` / `// TODO:` / `// BUG:` annotation — the reasoning behind code that was previously invisible to the graph — becomes a first-class symbol parented to the enclosing function, so it shows up in `search` (e.g. `search "retry"` surfaces a `HACK:` note about retrying) and `symbol`. Deterministic: extracted straight from the Go AST comment stream, no inference. Multi-line `//` rationale is captured as one symbol spanning the whole comment group.
