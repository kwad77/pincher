**Shippable methodology skills + `pincher init --target=claude-skills`.** Pincher's methodology layer now ships with the tool instead of living in any one user's home directory: five Claude Code skills under `plugin/skills/` — `pincher-loop` (the evidence-gated, context-frugal delivery loop, with its EGDL references), `pincher-onboard` (first contact with an unfamiliar repo: health → architecture → onboard_module → seeded ADRs in <10 calls), `pincher-review` (blast-radius-first review: interrogate the impact graph before the diff text), `pincher-debug` (failure triage: `investigate_failure` evidence ranking before any hypothesis grep), and `pincher-steward` (a scheduled maintenance heartbeat: doctor advisories, health drift, coach/adherence, ledger triage, ≤40-line report). The new `claude-skills` init target installs them to `~/.claude/skills/` (per-skill dirs, embedded in the binary): preview by default with `--write` to apply, idempotent re-runs, and an overwrite-refusal gate that compares the `version:` frontmatter line and never clobbers a newer user copy. Included in `--target=all` under the same preview contract; refused over the MCP `init` tool since the destination escapes `project_path`. The Claude Code plugin picks the same `skills/` directory up natively, so plugin installs get the skills for free.
