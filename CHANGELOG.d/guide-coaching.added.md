**`guide` is now a phase-aware coach and the next_steps adherence flywheel is closed (loop-substrate PR-15/17).** The front door used to return the generic architecture+search fallback (shape `unknown`) for nuanced tasks and never recommended the composites. `guide` now routes by task shape: a pasted stack trace (file:line frames, panic/traceback tokens) leads with `investigate_failure`; a directory-shaped task (trailing `/`, extensionless path, onboard/orient verbs) with `onboard_module`; pre-edit intent ("change/refactor/rename X", "what breaks") with `plan_change`; caller questions ("who calls", "callers of", "blast radius of <symbol>") with `trace`; resumption ("continue", "where was I") with a loop-ledger resume when `loop_checkpoints` exists and is non-empty (else `adr` list); and multi-question tasks with `batch` — composite recommendations are gated on the runtime registered-tools set, so the routing works before and after the PRs adding new composites merge, and every recommendation carries concrete args derived from the task. The legacy keyword path is preserved as the fallback. Separately, the `next_steps_adherence` counters (#1631) — stamped on every envelope but consumed by nothing — now feed back: the tracker keeps per-tool emitted/followed counts and `guide` orders its recommendations by historical followed-rate once a tool has ≥10 emissions this process (process-lifetime only, not persisted — no schema change), and `stats` surfaces a SESSION line `next_steps followed: X% (E emitted)` so a 0%-followed session is visible instead of silently unmeasured.
