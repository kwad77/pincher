`pincher init` no longer silently defaults to `--target=claude` ([#1862](https://github.com/kwad77/pincher/issues/1862)). Running it inside a non-Claude host (e.g. Codex) used to write a `CLAUDE.md` + `.claude/` PreToolUse hook the user never asked for. With no explicit `--target`, init now resolves the host: the agent pincher is running under (env signal — `CLAUDECODE` ⇒ Claude Code), then editor marker files, and refuses with the `--target` list rather than guessing when neither is conclusive. The MCP `init` tool gets the same treatment — an empty `target` no longer falls through `detect` to the claude fallback. Explicit `--target=X` is unchanged.
