**`mode=skeleton` retrieval ([#2046](https://github.com/kwad77/pincher/pull/2046)).** `symbol`/`symbols`/`context` accept an optional `mode` param. `mode=skeleton` renders a symbol from its **already-indexed** `Signature`/`ReturnType`/`Docstring` with the body elided — **DB-only, no file read or re-parse** — so it stays correct even after the source file is edited or deleted (immune to the byte-offset staleness path by construction). Container kinds (Class/Interface/Module/…) list their members' signatures via Parent linkage; `max_tokens` truncates the child list at a line boundary with a `… +N more` note; responses stamp `_meta.mode` + `tokens_saved_vs_full`. Pincher's in-lane analog of an AST code-compressor — ship a symbol's *shape*, not its body. Default `mode=full` is byte-identical to today (backward compatible).
