`pincher index` closes the onboarding loop with a one-line next-step ([#1710](https://github.com/kwad77/pincher/issues/1710) v0.92). A first-time index of a project printed its symbol/edge counts and then just stopped — a new user had no signal for what to do next. The non-hook output now appends `Next: run \`pincher setup\` … or \`pincher web\` …`, shown only on a human's (TTY) *first* index of a given project — a re-index, hook mode, `--json-summary`, and piped/scripted output are unchanged.
