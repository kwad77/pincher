**PHP extraction promoted to AST tier (1.0) via real tree-sitter (ADR-0008, Phase 2).** PHP `.php` files now extract through real upstream tree-sitter compiled to WASM (`wazero`, pure-Go / `CGO_ENABLED=0`) — the first Phase-2 language, behind the same per-file all-or-nothing dispatcher; `PINCHER_DISABLE_PHP_AST=1` reverts to the regex tier. QNs use PHP's `\` namespace separator and are keyed on `moduleQN` (namespace-blind, matching the regex tier) so symbol IDs stay stable; a `trait` is a scope-only container (its methods parent to it, matching the regex `scopeRE`, no separate Class symbol). Measured on guzzle (43 files): **0% parse errors, 100% symbol agreement with exact parity on every kind** (Class/Function/Interface/Method), plus **142 net-new IMPORTS** (`use` declarations the regex tier never captured) and a richer CALLS graph (1393→1626, including `new Foo()` constructor edges). Validated by an inline unit test, a no-leak-under-3000-reuses RSS test, and a marshaler fuzz target. Cost: binary +~0.8 MB (wasm 10.4→11.2 MB). **Breaking note:** re-indexing a PHP project changes some symbol IDs where tree-sitter scopes more precisely than the old regex tier — announced, not silent.
