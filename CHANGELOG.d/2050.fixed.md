**Release: an optional Homebrew tap-mirror auth failure no longer reds the whole release run ([#2050](https://github.com/kwad77/pincher/issues/2050)).** The `release.yml` "Mirror to tap repo" step already degraded gracefully when `HOMEBREW_TAP_TOKEN` was *unset* (warn + `exit 0`), but a *present-but-invalid* token (expired PAT / missing `contents:write`) let `git push` fail under `set -e` and failed the entire release job — first observed on v1.10.0, the first stable promotion since v1.0.0 (the Homebrew bump only runs when `minor % 10 == 0`, so v1.1–v1.9 had skipped it). The clone and push now degrade to a loud `::warning::` + `exit 0`: the authoritative artifacts (binaries, `SHA256SUMS`, the GitHub release, the main-repo formula commit) have all shipped before this optional convenience-mirror runs, so a dead tap token is surfaced (warning + the tracking issue) without false-failing the release. Rotating the token remains a separate manual step.
