New CLI subcommand `pincher test-impacted` closes the blast-radius loop locally: it runs the same diff → changed-symbols → impacted-tests analysis as the `changes` MCP tool (the pipeline is now shared via `server.AnalyzeChanges` rather than forked) and executes exactly the implicated Go tests, grouped per package as `go test <pkg> -run '^(TestA|TestB)$' -count=1`. Flags: `--scope unstaged|staged|all|base:<branch>`, `--dry-run`, `--timeout` (default 10m), `--max-tests`, `--json`. Conclusion-dense output (one line per package, detail only on failure, `IMPACTED: P packages, T tests — PASS|FAIL` summary, exit 0/1); non-Go impacted tests (e.g. `*.spec.ts`) are listed as "not runnable by this command" instead of silently dropped. Obvious follow-up: expose the same compute-and-run loop as an MCP tool so agents get it without shelling out.
