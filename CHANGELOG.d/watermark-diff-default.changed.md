**Loop-substrate PR-4': `_meta.watermark` on every envelope + #655 diff-context flips default-ON.** Every JSON tool response now stamps `_meta.watermark` (`g<generation>.c<callseq>`): the generation increments once per completed index pass, so equal generations between two responses guarantee the symbol graph did not change in between — loop agents key caches and resume-checkpoints on it instead of re-probing. The watermark survives `meta=lite` deliberately (thin clients need the loop contract too). Separately, the #655 diff-encoded-context feature graduates from opt-in to **default-ON** — exactly the rollout the v0.56 note planned ("default-off until perf validates, then default-on"; the #1320 chars/4 ApproxTokens fast path removed the perf concern). A repeat `context` call on an unchanged file now short-circuits to `{unchanged:true}` (~100 tokens); a changed file ships the symbol body as a line diff against what was last served. `PINCHER_DIFF_CONTEXT=0`/`off`/`false` restores the legacy ship-everything behavior. Together these collapse the dominant cost of long agent loops: iteration N+1 no longer re-pays for what iteration N already read.
