**C++ extraction promoted to AST tier (1.0) via real tree-sitter (ADR-0008, Phase 2 — completes Phase 2).** C++ files (`.cpp`/`.cxx`/`.cc`/`.hpp`/`.hh`) now extract through real upstream tree-sitter compiled to WASM (`wazero`, pure-Go / `CGO_ENABLED=0`), behind the per-file all-or-nothing dispatcher; `PINCHER_DISABLE_CPP_AST=1` reverts to the regex tier. (C files — `.c`/`.h` — stay on the regex tier.) class/struct/union → Class, enum → Enum, functions/methods → Function/Method; constructors and destructors are skipped (matching the regex tier, which requires a return type); an export-macro mis-parse (`class MODULE_API Name {…}`, the Unreal/Win32 convention) is recovered to the real type name; out-of-line `Ret Class::method(){}` definitions bind to their class. QNs are `moduleQN`-keyed with `::` (namespace-blind). `#include` directives emit IMPORTS (net-new). Measured on Catch2 (289 files): **13.8% parse errors** (the highest of any language — C++ is the hardest grammar and Catch2 is template/macro-heavy worst-case; those files gracefully fall back to regex, never worse than before), but the gain on the rest is the largest of any language: the C/C++ regex tier was barely functional (287 symbols, 14 functions, **zero methods**, 16 CALLS), while tree-sitter captures **1965 symbols** (1312 methods + 398 functions), **+1075 #include IMPORTS**, and **3407 CALLS (213×)**. Validated by inline unit + no-leak (3000 reuses) + fuzz; full `internal/ast` suite + `make corpus-test` green (no C++ in fixtures). Cost: binary +~3.5 MB (cpp grammar; wasm 20.3→23.8 MB — the binary is now ~58 MB with all ten grammars). **Breaking note:** re-indexing a C++ project changes many symbol IDs — tree-sitter extracts vastly more (methods, calls) than the old regex tier; announced, not silent.
