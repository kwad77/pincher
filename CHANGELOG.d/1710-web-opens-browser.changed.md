`pincher web` now opens the dashboard in your browser instead of only printing the URL ([#1710](https://github.com/kwad77/pincher/issues/1710) v0.92). When `web` is run interactively (stdout is a terminal) it launches the resolved dashboard URL via the platform shell-open helper — `rundll32` / `open` / `xdg-open` — so "open the dashboard" actually opens it. The URL is still printed (and a browser-launch failure falls back to it silently); `--json` mode and a new `--no-open` flag suppress the launch for scripted use, and a piped stdout never triggers it.
