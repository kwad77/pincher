**Ruby extraction promoted to AST tier (1.0) via real tree-sitter (ADR-0008, Phase 2).** Ruby `.rb`/`.rake` files now extract through real upstream tree-sitter compiled to WASM (`wazero`, pure-Go / `CGO_ENABLED=0`), behind the per-file all-or-nothing dispatcher; `PINCHER_DISABLE_RUBY_AST=1` reverts to the regex tier. Because Ruby's regex tier was the **0.70 "approximate"** tier, this is a **0.70 → 1.0** lift — the largest single quality jump of any language. `class`/`module` → Class (matching the regex `classRE`), `method`/`singleton_method` → Method inside a class or Function at top level (the `def self.x` / `def Klass.x` receiver is skipped), QNs keyed on `moduleQN` with `::` (namespace-blind). `require`/`require_relative`/`load` calls now emit IMPORTS (net-new — the Ruby regex tier had no import pattern). Measured on Sinatra (147 files): **0% parse errors, 90.6% symbol agreement**, **+220 net-new IMPORTS**, and a **17× richer CALLS graph** (811 → 13987 — a large win for `trace`/`neighborhood`, since the Ruby regex CALLS pass was especially thin). Validated by inline unit + no-leak (3000 reuses) + fuzz; full `internal/ast` suite + `make corpus-test` green (no `.rb` in fixtures → no golden change). Cost: binary +~2.1 MB (wasm 14.1→16.3 MB). **Breaking note:** re-indexing a Ruby project changes some symbol IDs (and lifts confidence 0.70→1.0) where tree-sitter scopes more precisely than the old regex tier.
