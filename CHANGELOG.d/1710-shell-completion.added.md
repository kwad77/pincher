`pincher completion <bash|zsh|fish>` prints a shell completion script ([#1710](https://github.com/kwad77/pincher/issues/1710) v0.92). pincher has 18 subcommands; until now `pincher <TAB>` completed nothing. Add `eval "$(pincher completion bash)"` (or the zsh/fish equivalent) to your shell rc and the subcommand at position 1 tab-completes. The completion list is generated from a single `pincherSubcommands` source of truth, and a drift-gate test pins it to the subcommands `main()` actually dispatches — so the scripts can't go stale.
