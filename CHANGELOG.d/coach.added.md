- `coach` MCP tool — retro-coaching from pincher's own recorded usage telemetry. Mines the per-call event log (`session_tool_calls`), the #241/#1632 query-failure counters, and `hook_invocations` for the current session (or trailing 7 days) and returns priced findings — "you did X N times; pattern Y would have cost ~Z fewer tokens" — every number computed from recorded telemetry and carrying a `basis` string documenting the arithmetic. Patterns: `single_fact_burst` (batch with `symbols`; priced at (N−1) × the measured `_meta` envelope overhead), `unbudgeted_heavy_context` (cap with `fields`/`lite`; priced at Σ(tokens_used − 800)), `zero_result_churn` (recover with `why_empty`; priced from `tokens_burned_on_failures`), `hook_fall_through` (ignored PreToolUse redirects; counts-only on schemas without per-row token estimates). Honest by construction: re-read-of-same-target detection is deliberately dropped (events store no arguments hash), and fewer than 10 recorded calls returns empty findings plus a note instead of extrapolating.
