A bare `pincher` typed into a terminal now prints a short orientation instead of silently hanging ([#1710](https://github.com/kwad77/pincher/issues/1710) v0.92). pincher is an MCP server: with no subcommand it falls through to the stdio loop and blocks on stdin — for a real client that stdin is a JSON-RPC pipe, but for a human at a terminal it just looked hung. An interactive TTY on stdin (with no `--http` and no `--no-stdio`) is now detected as a human and answered with a one-screen "here's what pincher is, here's the command you want" — pointing at `pincher setup`, `index`, `web`, and `--help`. A piped stdin (every real MCP client) and `pincher supervised` run the server exactly as before.
