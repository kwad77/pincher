**`max_tokens` response budget on `context` + `symbols` (loop-substrate PR-5).** Per-call cap in approximate tokens (same chars/4 heuristic as `_meta.tokens_used`; honors the exact-BPE opt-in). Deterministic degradation order on `context`: the primary symbol source is cut at a line boundary first, then callees, then imports return metadata-only entries with `source_omitted:true` — the span-estimate gate means omitted entries skip the byte-offset disk read entirely. On `symbols` the budget applies across the batch in input order. When the cap fires, `_meta.warnings_v2` carries `code=budget_truncated` with per-section counts so an agent can fetch the omitted bodies selectively instead of re-issuing the whole call. `0`/omitted = unlimited — exact legacy shape; composes with `fields=`, `lite=true`, and the `#655` diff-context path (the budget trims whatever body the diff shaping decided ships). Motivated by a measured dogfood failure: a `context` call on a 2,800-line function returned a ~68 KB envelope mid-benchmark and blew the agent's probe budget; with `max_tokens` a loop can hard-bound every call.
