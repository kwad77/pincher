`pincher setup` — a new interactive install wizard ([#1710](https://github.com/kwad77/pincher/issues/1710) v0.92). Running `pincher setup` in a terminal opens an arrow-key wizard: a checklist of every editor/agent target with detected hosts pre-checked, a contextual options step (global rules, the Claude PreToolUse hook, git hooks — only the applicable ones are shown), a file-write review screen, and a post-setup step that can index the project. `pincher init --target=<name>` remains the scripted/non-interactive path; `setup` refuses to run without a TTY and points there. Built on `golang.org/x/term` (already in the dependency tree) — no new module footprint.
