`format="toon"` on `search` and `trace`: TOON (Token-Oriented Object Notation) tabular rendering of the row payload, carried in `results_toon` (replacing the `results`/`hops` array; the `_meta` envelope stays JSON — MCP structuredContent is JSON by spec). Encoder-only subset in `internal/server/toon.go` (pincher never parses TOON; no new dependency): uniform object arrays render as `key[N]{f1,f2,...}:` with one bare comma-delimited row per element, strings quoted only when needed, sorted keys for deterministic output. Measured on the same 20-hit search fixture that gates `format=text`: TOON ≈ 0.50× the JSON results-array token cost (text ≈ 0.45×; TOON ≈ 1.09× text — it additionally carries bare `name` and `file` columns). Unknown `format` values still warn and fall back to json. **Opt-in only** — comprehension A/B via loopbench is REQUIRED before any default-format change; the token ratio alone doesn't establish that agents drive follow-up calls as reliably from TOON rows.
