`pincher callflow --symbol=NAME` renders a Mermaid call-flow diagram — callers and callees of a symbol out to a bounded depth ([#1852](https://github.com/kwad77/pincher/issues/1852)). Because pincher's CALLS edges are deterministic AST facts, the diagram is exact rather than inferred. Output pastes straight into Markdown, a GitHub comment, or mermaid.live. `--direction` selects callers/callees/both, `--depth` (1-4) bounds the walk, and a node cap keeps a hub symbol from rendering an unreadable graph.
