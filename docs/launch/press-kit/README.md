# v1.0 press kit inventory

Draft inventory for [#1538](https://github.com/kwad77/pincher/issues/1538).
Populate final image assets after the landing page and demos are recorded.

## Assets

| Asset | Target file | Source | Notes |
|---|---|---|---|
| Logo mark | `logo-mark.png` | existing project/logo asset or generated export | Transparent background, square crop |
| Dashboard screenshot | `dashboard.png` | v1.0 dashboard | No private paths or user data |
| Fresh-clone demo still | `fresh-clone-demo.png` | short demo recording | Use the frame showing first useful query |
| Edit-confidence demo still | `edit-confidence-demo.png` | short demo recording | Use the frame showing `plan_change` or `investigate_failure` |
| Host matrix screenshot | `host-matrix.png` | landing page or docs table | Show supported hosts without implying unsupported protocol features |

## Rules

- Do not include private repository paths, shell history, API keys, or personal
  editor state.
- Prefer 16:9 screenshots for blog/social reuse.
- Keep generated PNGs below 2 MB when possible.
- Re-capture assets after the final v1.0 binary and landing page are in place.
