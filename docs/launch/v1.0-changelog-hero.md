## [1.0.0] - 2026-<<MM-DD>> - Stable local code intelligence for agents

Pincher 1.0 freezes the local MCP tool surface for agent-driven code
navigation. The release line turns the Phase 4 composite tools and the Phase 5
RC hardening work into a compatibility promise: stable tool schemas, stable
`_meta` response envelope conventions, documented host setup, forward-only
SQLite migrations, and explicit support boundaries.

### What Is Stable

- MCP tools for search, symbol lookup, context, trace, graph queries,
  diagnostics, and the Phase 4 composites.
- CLI install, setup, doctor, stats, verify, project-management, and export
  workflows documented under `docs/reference/cli.md`.
- The v1.0 frozen-surface contract in `docs/adr/0002-v1-frozen-surface.md`.
- Per-language support tiers in `docs/reference/languages.md`.
- Host setup paths for Claude Code, Cursor, VS Code Copilot Chat, Codex,
  JetBrains, Zed, and the HTTP dashboard.

### What 1.0 Deliberately Defers

- Plugin extractors are deferred to 1.x per ADR-0003.
- Team/shared-index server mode is outside the v1.0 local SQLite boundary.
- MCP resources, completions, icons, and progress notifications remain
  post-1.0 protocol-surface work unless promoted by a later ADR.

### Upgrade Notes

- Reinstall the binary using the v1.0 release asset or package manager path.
- Run `pincher doctor` after first launch to confirm schema version, project
  staleness, extraction failures, and slow-query state.
- Existing databases migrate forward on open. Do not downgrade a migrated DB
  without restoring a backup.
