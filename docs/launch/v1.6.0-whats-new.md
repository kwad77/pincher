# pincher v1.6.0 — What's New (draft for the GH release; dev channel)

> Fact-check note: the pre-merge draft of this document led with the
> nine-language tree-sitter rollout. That work **shipped in v1.4.0**
> (see the v1.4.0 changelog entry); this document covers what actually
> lands between `v1.5.0` and `v1.6.0` — #2002 through #2009 plus the
> #1974/#1975 startup-discipline fix. Every number cited is measured,
> per the project's no-invented-numbers rule.

## Headline: the session just got ~15k tokens lighter (schema-diet default flip)

`PINCHER_TOOLSET` now defaults to **core** (the 10 loop-essential
tools: `search`, `symbol`, `symbols`, `context`, `trace`, `changes`,
`batch`, `loop`, `verify_change`, `guide`) and `PINCHER_SCHEMA_STYLE`
to **lean** (first-sentence descriptions, arg descriptions capped at
~120 chars) — **~3.0k approx tokens of tools/list advertisement instead
of ~18.4k**, re-read by MCP hosts every turn.

This is the measured decision #2003 deferred, delivered by the scale
round (#2005): at 10x messy-corpus scale over the same 8-question run,
full/rich burned **1,440,781 total tokens vs 475,246 for core+lean at
identical 8/8 accuracy** — 3.0x waste from schema advertisement alone.

Nothing is removed. All 34 tools stay registered in every mode — HTTP
`POST /v1/<tool>`, the OpenAPI spec, and `batch` sub-query dispatch
keep the full surface — and `guide` names the escape hatches when it
recommends a non-advertised tool. Opt out with `PINCHER_TOOLSET=full`
(or `--toolset full`) + `PINCHER_SCHEMA_STYLE=rich` to restore the
pre-v1.6 surface. MINOR per RELEASING.md: a behavior flip with an env
opt-out. The default surface has its own contract gate
(`TestToolContract_DefaultSurface`); the golden keeps pinning full/rich.

## Trust the graph (it's now in the contract)

`trace`/`changes`/`verify_change` descriptions — rich **and** lean —
now state that graph answers are authoritative for
caller/callee/count/blast-radius questions: act on them, re-verify with
text search only on a mid-task watermark change or an explicit warning
(#2009). Why: an n=3 benchmark showed agents coached to trust the graph
**halve their turns at equal accuracy (48/48)** and stop re-grepping
answers they already have. Baking it into descriptions reaches every
client without system-prompt coaching.

## Startup DB discipline (#1974/#1975)

`db.Open` no longer takes a write transaction when the store is already
at the binary's schema version, and read-only surfaces (`pincher web`,
`bench`, health checks, `init`'s dashboard footer) open the store
read-only outright — a long-running `pincher index` can no longer
starve every other pincher process on the machine into a
`database is locked` death. Schema migration of an existing store is
now an explicit, loud decision: tagged release builds migrate
automatically with a pre-migration snapshot in `<data-dir>/backups/`;
dev builds refuse without `PINCHER_ALLOW_MIGRATE=1`. (v1.6.0 itself
ships **zero migrations** — schema stays v41.)

## Quality of life

- **Hook v2.1 (#2006)** — `Glob` calls get advisory redirects when the
  pattern targets code in an indexed project; `pincher init
  --target=claude` bakes `--data-dir` into installed hooks so they
  resolve the right index (a bare `hook-check` against the platform
  default silently passed everything through).
- **`pincher init --dco-hook` (#2008)** — opt-in `prepare-commit-msg`
  hook appending `Signed-off-by` from your git identity;
  merge/squash-aware, duplicate-safe, never overwrites a non-pincher
  hook (no `--force` escape — sign-off is an attestation).

## Benchmark infrastructure (the receipts)

The messy-corpus generator and ladder (#2002), and the scale +
repetition round (#2005) — the falsification gates that produced the
diet decision — ship in-tree under `scripts/loopbench/`, including the
`--scale N` corpus mode, the `messy-scale-8q` task set with verified
answer key, and `out/scale-20260611/RESULTS-scale.md` with the
hand-graded verdicts.

## Compatibility

- Tools: 34 → 34 (none added, none removed; no input-schema changes).
- Schema: v41 → v41 (zero migrations).
- The only observable behavior flips are the core/lean defaults
  (env/flag opt-out above) — MCP clients that pin specific
  non-core tools over `tools/call` should set `PINCHER_TOOLSET=full`
  or use HTTP `/v1/<tool>`.
- Frozen-surface review (ADR-0002) and the focused adversarial review
  are recorded in
  [docs/release-signoff-v1.6.0.md](../release-signoff-v1.6.0.md).
