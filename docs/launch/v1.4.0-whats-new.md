# pincher v1.4.0 — What's New (draft for the GH release; dev channel)

## The loop release

v1.4.0 turns pincher from a token-saving lookup layer into **loop-harness
infrastructure**: durable work-state, bounded envelopes, delta reads, server-side
pipelining, instrumented verification, and self-coaching — built and validated by
running the development itself as an evidence-gated loop, with every shipped
number measured rather than estimated.

### Loop state that survives the context window
- **`loop` tool** (schema v40): `start | checkpoint | list | resume`. Append-only
  checkpoints {claim, decision, confidence, reopen_trigger, evidence}, watermark-
  stamped; `resume` = one bounded brief (default ~800 tokens, `max_tokens` to
  shrink it) — a fresh session, or a different model, picks up mid-flight work in
  a single call. Eviction-shaped receipts teach the window to hold pointers while
  the ledger holds payloads.
- **`_meta.watermark`** (gN.cM) on every envelope: equal generations guarantee the
  symbol graph didn't change between two responses; `resume` warns on drift.

### Bounded, delta, and dense envelopes
- **`max_tokens`** on context/symbols (and composed everywhere sensible):
  deterministic degradation, `budget_truncated` warnings — truncation is never
  silent.
- **Diff-context default-ON** (#655 graduates): repeat `context` on an unchanged
  file = `{unchanged:true}` (~100 tokens). Per-connection and full-fidelity-only
  (budgeted/projected/REST serves never touch the cache); `diff=false` bypasses
  it per call, `PINCHER_DIFF_CONTEXT=0` opts out process-wide.
- **`detail=skeleton`**: deterministic structural source compression — a
  representative 120-line mixed-flow function compresses to under 25% of its
  full-source tokens, every CALLS-edge callee guaranteed present.
- **Envelope compression**: session-delta `_meta` (capabilities once per session,
  ~74 tokens/call saved), `format=text` (0.45× vs JSON on list payloads),
  opt-in `format=toon` (0.50× vs JSON), ditto-compressed trace hops under
  `compact`.
- **`count_only` + `assert_graph`**: conclusions, not rows — caller counts and
  passing assertions cost tens of tokens; failures report violations only.

### One call where N used to go
- **`batch`**: up to 12 read-only sub-queries in one envelope under a shared
  budget, per-entry slim meta, sub-error isolation — and **chain mode**:
  `from:{query,select,into}` + `quiet` keep intermediate results server-side
  (measured ~0.67× vs the equivalent two calls).
- **`verify_change`**: the post-edit gate composed — changed symbols, ranked
  tests, **predicted-vs-actual blast radius** against the plan_change cache
  (`unpredicted_impact` / `plan_stale` honesty), orphan check.
- **`pincher test-impacted`** (CLI): compute the blast radius AND run exactly
  those tests; conclusions + exit code.

### Trust hardening
- **Dispatch-blind verdict caps**: dead-code candidates that interface dispatch
  could be calling are never "high confidence" again (root cause: case-folded
  interface-method matching; the nine measured false positives — pincher's own
  live tree-sitter `extract` methods — are pinned tests).
- **Python cross-file CALLS +44%** (one-hop type inference at confidence 0.6 +
  unique-suffix resolution that never guesses between candidates).
- **`.pincherignore`** (gitignore semantics via gocodewalker CustomIgnore) +
  `settings_flood` doctor advisory — kills the 27k-junk-symbols-from-data/
  failure class; GC of newly-ignored files proven.

### The harness coaches itself
- **`guide`** routes by task shape (stack trace → investigate_failure, who-calls
  → trace, resume → loop, multi-question → batch), recommendations ranked by
  measured adherence.
- **`coach`**: priced findings from your real usage telemetry — every number
  carries its computation basis.
- **Hook redirect v2**: budgeted Read redirects + honest per-redirect savings
  measurement (est_tokens_served vs the Read's real baseline; schema v41).
- **Five installable skills** (`pincher init --target=claude-skills`): loop,
  onboard, review, debug, steward — the methodology layer ships with the tool.

### Also in v1.4: the AST-tier language wave (ADR-0008)
Real upstream tree-sitter compiled to WASM (pure Go, `CGO_ENABLED=0`): Rust,
Java, C#, TypeScript/TSX, Swift, Kotlin, PHP, Ruby, and C++ all promote from
the regex tier to AST-tier extraction at confidence 1.0, with per-file graceful
fallback to regex on parse errors — never worse than before. Ruby is the
largest single lift (0.70 → 1.0). Re-indexing changes some symbol IDs where
tree-sitter scopes more precisely — announced, not silent.

### Measured, honestly
Every headline number above was measured on real fixtures and recorded in the
changelog entry that ships it (per-language parse-error rates and
symbol-agreement percentages included). Methodology docs live in
`docs/methodology/`; the development itself ran as an evidence-gated loop with
its work-state in pincher's own loop ledger.

Schema v39 → **v41** (additive: `loop_checkpoints`, hook-savings telemetry
columns). 29 → **34 tools**. All frozen-surface changes additive per ADR-0002.
