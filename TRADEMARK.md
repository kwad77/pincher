## Why this exists

`pincherMCP` is intentionally a single-maintainer project pre-1.0. Allowing
arbitrary forks to publish under the same name would make it impossible for
users to tell which artifact is the canonical one and would dilute the safety
guarantees the official releases ship with (signed binaries, install
validation, the release-channel rules in [RELEASING.md](RELEASING.md)).
This notice keeps the names tied to the canonical project without limiting
the open-source freedoms the MIT license grants over the code itself.

## Questions

<https://github.com/kwad77/pincher/issues> and tag it `trademark`. Honest
descriptive use ("a tool inspired by pincherMCP") is almost always fine;
the concern is only about uses that could confuse users about which project
they're looking at.
